# Instructions pour ajouter l'image de la mosquée

## Étapes à suivre :

1. **Sauvegarder l'image fournie** sous le nom `dakar-mosque.jpg`
2. **Placer le fichier** dans le dossier : `quran-app/assets/images/`
3. **Chemin complet** : `quran-app/assets/images/dakar-mosque.jpg`

## Alternative si l'image ne s'affiche pas :
- Vous pouvez aussi utiliser l'URI direct dans le code en remplaçant :
  `source={require('@/assets/images/dakar-mosque.jpg')}`
- Par :
  `source={{uri: 'chemin-vers-votre-image'}}`

L'image sera utilisée comme arrière-plan minimaliste de la page d'accueil avec le gradient vert et or.
